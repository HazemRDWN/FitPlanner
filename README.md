# FitPlanner

A fitness and workout planner: build routines, log workouts, and track progress.
SW 302 – User Interface Development, Zewail City. Phase 2: static prototype (HTML5 + Tailwind CSS).

## Pages

| Page | File |
|---|---|
| Home | `index.html` |
| Log in / Sign up | `login.html`, `register.html` |
| Dashboard | `dashboard.html` |
| Exercise library | `exercises.html` |
| Exercise detail | `exercise-detail.html` |
| Routine builder | `routine-builder.html` |
| Active workout | `workout.html` |
| History & export | `history.html` |
| Profile & settings | `settings.html` |

Every page has a desktop and a mobile layout, in dark and light mode.

## Run it

Open `index.html` in a browser. The built CSS (`dist/output.css`) is included.

## Develop

```bash
npm install
npm run dev     # rebuilds dist/output.css on every save
npm run build   # builds dist/output.css on command
```

Styles live in `src/style.css` (theme colours and fonts). Icons are in `assets/`.
